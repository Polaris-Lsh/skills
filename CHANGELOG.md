# Changelog

All notable changes to this repository are documented here. Releases use semantic version tags such as `v1.0.1`.

## [Unreleased]

## [1.0.1] - 2026-11-19

### Added

- Repository-level bilingual README, validation script, CI validation, tagged release workflow, security policy, and changelog.

### Changed

- Reframed the skill as an explicitly invoked, lightweight writing workflow.
- Merged the former baseline and editing rules into one `核心规则` section.
- Added a direct-drafting path for tasks that start without source text.
- Restricted the full normative review to explicit requests for strict conformance.
- Expanded both skill READMEs with purpose, use cases, and drafting/editing/review examples.

## [1.0.0] - 2026-11-18

### Added

- Initial Chinese-first technical writing skill.
- Full style guide, personal terminology reference, heuristic checker, and bilingual documentation.
