# 个人技术术语表

本表只在用户明确要求统一术语或审查术语时参考，不参与日常轻量改写。它是中文优先写作的本地约定，不是 ASD-STE100 官方词典。代码、命令、路径、界面原文和引用中的文本不受普通叙述替换规则约束。

## 1. 常用名词

| 中文首选 | 英文对应 | 使用条件 |
|---|---|---|
| 缓存 | cache | 普通叙述用“缓存”；代码标识符保留 `cache`。 |
| 配置 | configuration / config | 普通叙述用“配置”；配置项名或文件名保留原样。 |
| 仓库 | repository / repo | 普通叙述用“仓库”；产品界面原文保留英文。 |
| 日志 | log | 普通叙述用“日志”；日志字段名保留原样。 |
| 命令 | command | 普通叙述用“命令”；实际命令使用行内代码。 |
| 标识符 | identifier | 指代码中的名称，不与普通“名称”混用。 |
| 参数 | parameter | 指函数或接口定义中的形式参数。 |
| 实参 | argument | 指调用时传入的实际值；项目已有约定时服从项目。 |

## 2. 易混动作

| 首选词 | 本地定义 | 不要混淆为 |
|---|---|---|
| 检查 | 查看内容或状态，不暗含完整判定过程。 | 不一定等于“验证”。 |
| 验证 | 依据预期结果或判据判断是否满足要求。 | 不只是“查看”。 |
| 确认 | 核实一个指定事实或状态。 | 不自动包含完整测试。 |
| 删除 | 使数据或对象不再存在。 | 不一定等于“移除引用”。 |
| 移除 | 解除包含、连接或引用，不必然销毁对象。 | 不自动等于“删除数据”。 |
| 启动 | 使程序或服务进入运行状态。 | 不与一般动作的“开始”轮换。 |
| 停止 | 使程序或服务结束运行。 | 不自动表示卸载或删除。 |

这些定义用于保持一致，不覆盖项目或行业的精确定义。遇到不同含义时，先确认，再修改术语表。

## 3. 常用简明替换

仅在含义完全相同时采用：

| 冗长表达 | 首选表达 |
|---|---|
| 对日志进行分析 | 分析日志 |
| 对配置进行修改 | 修改配置 |
| 对结果进行验证 | 验证结果 |
| 利用工具完成任务 | 使用工具完成任务 |
| 在运行之前 | 在运行前 |
| 在运行之后 | 在运行后 |
| 为了能够启动服务 | 为了启动服务 |

不得机械替换“利用、采用、实现、完成”等词。固定技术名称和不同语义优先。

## 4. 新增术语流程

1. 写出唯一中文首选词和必要英文对应。
2. 写出一句可判定边界的定义。
3. 记录允许保留英文的场景。
4. 列出容易混淆但不可互换的近义词。
5. 检查同一文档和相关文档中的既有用法。
6. 在下表记录变更原因；没有长期复用价值时不加入。
